Feature Research Document

Hudl Wyscout

Player Reports and Comparisons

Product

Hudl Wyscout

Selected Feature

Player Reports and Comparisons

Dataset Used

FIFA World Cup 2026 Player Performance Dataset

Purpose

Research the existing product feature and identify how the idea relates to the
FIFA tabular dataset.

Why this feature was selected

A player report is highly relevant to the dataset because the dataset contains many player-level attributes that can be
summarized and compared.

Feature Research

1. Wyscout provides detailed reports for players, matches, teams and competitions. Its player reports include career
information, match statistics and position-relevant information.

2. Wyscout also supports comparison through player lists and reporting tools. Its current analysis workflow includes
statistics, filters and rankings for players and teams.

3. A player report turns many individual columns into a more understandable profile. This is useful when a dataset
contains dozens of attributes.

4. For the FIFA dataset, a report could combine basic player information with goals, assists, passing, physical
attributes, rating and other performance fields.

How it could relate to the FIFA dataset

Possible project implementation: generate a one-page player report containing personal details, key statistics,
performance indicators and a comparison with other players in the same position.

Important distinction

This document describes the researched product feature and a possible adaptation to the user's FIFA dataset. It does
not claim that the FIFA dataset contains proprietary data from the named product, and it does not claim that the
project reproduces the product's proprietary algorithms.
