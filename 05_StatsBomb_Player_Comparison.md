Feature Research Document

Hudl StatsBomb

Side-by-Side Player Comparison with Radars

Product

Hudl StatsBomb

Selected Feature

Side-by-Side Player Comparison with Radars

Dataset Used

FIFA World Cup 2026 Player Performance Dataset

Purpose

Research the existing product feature and identify how the idea relates to the
FIFA tabular dataset.

Why this feature was selected

The FIFA dataset has multiple performance features, so side-by-side comparison can turn many columns into an
easy visual comparison.

Feature Research

1. Hudl StatsBomb provides side-by-side player and team comparisons with radar visualisation. Players can be
compared across competitions and date ranges.

2. StatsBomb radars are designed around position-specific statistical production. Their published methodology
explains that radar values are normalized per 90 minutes and compared with positional reference distributions.

3. The current StatsBomb platform also supports percentile displays, which can make metrics with different units
easier to compare.

4. For the FIFA dataset, a similar radar could display selected features such as goals, assists, passing, physical
performance and rating for two players.

How it could relate to the FIFA dataset

Possible project implementation: select two players, normalize the selected metrics, and display them in a radar chart
with a small supporting comparison table.

Important distinction

This document describes the researched product feature and a possible adaptation to the user's FIFA dataset. It does
not claim that the FIFA dataset contains proprietary data from the named product, and it does not claim that the
project reproduces the product's proprietary algorithms.
