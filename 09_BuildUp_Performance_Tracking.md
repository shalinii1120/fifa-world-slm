Feature Research Document

BuildUp

Player Performance Tracking Over Time

Product

BuildUp

Selected Feature

Player Performance Tracking Over Time

Dataset Used

FIFA World Cup 2026 Player Performance Dataset

Purpose

Research the existing product feature and identify how the idea relates to the
FIFA tabular dataset.

Why this feature was selected

The FIFA dataset is focused on player performance, so tracking how performance changes across matches or
periods is a natural extension of the dataset.

Feature Research

1. BuildUp describes performance tracking over time as part of its football-data and team workflows.

2. Its Player App provides a personal view of matches, statistics and progress over time. The platform states that
each match can add to a shareable player profile.

3. Tracking over time can reveal whether a player's performance is stable, improving or changing across a season or
competition.

4. For the FIFA dataset, this feature would require a suitable time or match identifier. If the supplied dataset does not
contain repeated observations for the same player across time, the feature should be presented as a product-inspired
design idea rather than a directly computed result.

How it could relate to the FIFA dataset

Possible project implementation: if match/season observations are available, plot player rating, goals, assists or other
metrics across matches or periods.

Important distinction

This document describes the researched product feature and a possible adaptation to the user's FIFA dataset. It does
not claim that the FIFA dataset contains proprietary data from the named product, and it does not claim that the
project reproduces the product's proprietary algorithms.
