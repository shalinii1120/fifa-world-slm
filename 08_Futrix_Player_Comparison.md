Feature Research Document

Futrix Scout

Player Comparison and Similar Players

Product

Futrix Scout

Selected Feature

Player Comparison and Similar Players

Dataset Used

FIFA World Cup 2026 Player Performance Dataset

Purpose

Research the existing product feature and identify how the idea relates to the
FIFA tabular dataset.

Why this feature was selected

Comparison is useful for the FIFA dataset because many player attributes can be used to identify players with similar
performance profiles.

Feature Research

1. Futrix Scout provides side-by-side player comparison, with scores, projections and trends aligned row by row.

2. Its Similar Players tool links a player to statistically similar profiles, giving scouts alternative targets.

3. The product describes a multidimensional evaluation model and uses multiple scouting dimensions rather than a
single statistic.

4. For the FIFA dataset, a simpler version can calculate similarity from selected standardized attributes such as age,
goals, assists, passing, physical statistics and player rating.

How it could relate to the FIFA dataset

Possible project implementation: select one player and return a comparison table plus a list of players with similar
values across selected FIFA performance features.

Important distinction

This document describes the researched product feature and a possible adaptation to the user's FIFA dataset. It does
not claim that the FIFA dataset contains proprietary data from the named product, and it does not claim that the
project reproduces the product's proprietary algorithms.
