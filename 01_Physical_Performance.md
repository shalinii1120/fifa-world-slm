Feature Research Document

FIFA Player App

Physical Performance Metrics

Product

FIFA Player App

Selected Feature

Physical Performance Metrics

Dataset Used

FIFA World Cup 2026 Player Performance Dataset

Purpose

Research the existing product feature and identify how the idea relates to the
FIFA tabular dataset.

Why this feature was selected

This is a strong match for the FIFA dataset because the dataset includes physical/player-performance attributes,
while FIFA describes physical metrics such as distance covered at different speed thresholds, high-speed actions and
maximum speed.

Feature Research

1. The FIFA Player App gives players access to individual performance data shortly after a match. FIFA states that its
physical-performance data is collected through an in-stadium tracking system using multiple cameras.

2. The physical metrics include distance covered at different speed thresholds, the number of actions above 25 km/h
and maximum speed. These measures can be displayed on positional heat maps.

3. For a FIFA player-performance dataset, this feature can be represented as a group of numerical performance
attributes. It can help users understand how physically active a player was during a match.

4. A similar implementation for the project could show a player's physical values together with other attributes such as
age, position, goals, assists, stamina and passing-related statistics.

How it could relate to the FIFA dataset

Possible project implementation: a player-performance dashboard with cards for distance/speed-related metrics, a
comparison view between players, and a visual summary of physical performance.

Important distinction

This document describes the researched product feature and a possible adaptation to the user's FIFA dataset. It does
not claim that the FIFA dataset contains proprietary data from the named product, and it does not claim that the
project reproduces the product's proprietary algorithms.
