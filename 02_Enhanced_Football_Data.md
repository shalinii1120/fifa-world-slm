Feature Research Document

FIFA Player App

Enhanced Football Data Metrics

Product

FIFA Player App

Selected Feature

Enhanced Football Data Metrics

Dataset Used

FIFA World Cup 2026 Player Performance Dataset

Purpose

Research the existing product feature and identify how the idea relates to the
FIFA tabular dataset.

Why this feature was selected

The dataset contains event/performance-style statistics such as goals, assists and passing attributes. FIFA's app
combines enhanced event data with tracking data to describe player actions.

Feature Research

1. FIFA describes enhanced football data metrics as measures calculated from event data collected by football
performance analysts and combined with tracking data.

2. Examples given by FIFA include movement to receive the ball, whether a distribution action broke opposition lines,
and pressure applied to an opponent in possession.

3. This feature is useful because football performance is not represented only by goals. A player can contribute
through passing, movement, pressure and other actions.

4. For the project dataset, the feature can be treated as an event/performance-analysis layer that complements basic
player attributes and statistics.

How it could relate to the FIFA dataset

Possible project implementation: show a player's attacking, passing and defensive/event contributions in a structured
player profile and allow comparison across players or positions.

Important distinction

This document describes the researched product feature and a possible adaptation to the user's FIFA dataset. It does
not claim that the FIFA dataset contains proprietary data from the named product, and it does not claim that the
project reproduces the product's proprietary algorithms.
