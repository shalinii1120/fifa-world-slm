Feature Research Document

Hudl StatsBomb

Player Evaluation using Performance Metrics

Product

Hudl StatsBomb

Selected Feature

Player Evaluation using Performance Metrics

Dataset Used

FIFA World Cup 2026 Player Performance Dataset

Purpose

Research the existing product feature and identify how the idea relates to the
FIFA tabular dataset.

Why this feature was selected

The dataset is intended for player-performance analysis, and StatsBomb uses advanced metrics to evaluate player
actions beyond simple counting statistics.

Feature Research

1. Hudl StatsBomb describes player evaluation as part of its football analytics platform and highlights metrics such as
On-Ball Value (OBV).

2. OBV evaluates actions according to their impact on a team's likelihood of scoring or conceding. This provides a
way to look beyond basic totals.

3. StatsBomb also provides contextual rankings and position/team profiles so performance can be viewed against
relevant groups.

4. For the FIFA dataset, a simplified evaluation layer could combine available performance attributes into a
transparent player-performance profile rather than claiming to reproduce StatsBomb's proprietary metrics.

How it could relate to the FIFA dataset

Possible project implementation: create a player evaluation page that summarizes the dataset's available metrics and
compares a player's values with players in the same position.

Important distinction

This document describes the researched product feature and a possible adaptation to the user's FIFA dataset. It does
not claim that the FIFA dataset contains proprietary data from the named product, and it does not claim that the
project reproduces the product's proprietary algorithms.
