Feature Research Document

Hudl Wyscout

Advanced Player Search and Filters

Product

Hudl Wyscout

Selected Feature

Advanced Player Search and Filters

Dataset Used

FIFA World Cup 2026 Player Performance Dataset

Purpose

Research the existing product feature and identify how the idea relates to the
FIFA tabular dataset.

Why this feature was selected

The dataset has player attributes such as position, team, nationality, age and performance statistics, making filtering
and searching directly relevant.

Feature Research

1. Wyscout provides search and query tools for navigating performance and career data, reports and videos.

2. Its advanced search allows users to filter by competition, timeframes, positions/zones and football KPIs. Filters can
also be grouped around attacking, defensive, finishing, passing and goalkeeping areas.

3. Search results can be used to select players and create player lists. This makes filtering useful for scouting and
shortlisting.

4. For the FIFA dataset, the same idea can be applied to filter players by position, team, nationality, age, goals,
assists, passing or other available attributes.

How it could relate to the FIFA dataset

Possible project implementation: a filter panel where users select position, team, age range and performance
thresholds, followed by a list of matching players.

Important distinction

This document describes the researched product feature and a possible adaptation to the user's FIFA dataset. It does
not claim that the FIFA dataset contains proprietary data from the named product, and it does not claim that the
project reproduces the product's proprietary algorithms.
